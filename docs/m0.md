# M0 — Contract + scaffold

Freeze the seams. After M0, FE and BE build in parallel against same contract, neither needs the other or a real model.

**Exit test:** contract suite green; FE renders fixture hole from mock SSE.

## Deliver

- **Repo scaffold.** npm workspaces: `apps/web`, `apps/api`, `packages/types`. Lint passes.
- **Types package.** `State`, `Node`, `Hole`, `Event`. Single source, imported by both sides.
- **DB schema.** SQLite migrations from README (users, holes, nodes). Seed fixture hole.
- **Event spec.** SSE list below, documented in types.
- **Mock SSE server.** No model. Plays a scripted run per fixture.
- **Playwright harness.** Boots mock + FE, seeds fixture, one smoke test.

## Event spec

One stream per ask. Ordered, absolute:

```
node.pending  → card exists, no text
node.meta     → title, sources, followups (envelope, parsed pre-body)
node.token    → body chunk, repeat
node.done     → status answered
node.error    → failed + reason
```

`node.meta` before first `node.token`. Retry = new stream, same node id.

## Mock SSE

- Serves fixture: pending → meta → tokens → done.
- Variants: slow stream, mid-stream fail, empty sources.
- Envelope header stripped, never leaks into body.

## Contract suite

- Types compile both sides.
- Mock events validate against `Event` schema.
- Envelope parser: meta extracted, body untouched.
- Fixture hole renders as a card.

## Non-goals

No real model, no search, no auth. No canvas layout, no styling polish. M1–M7 fill these.
