# M2 — Asking + streaming

Make the tree grow. FE talks to mock SSE only; no real model, no backend graph. Presets hardcoded.

**Exit test:** Playwright vs mock SSE — pending, streaming, answered, failed states; title, sources, follow-up chips appear.

## Deliver

- **Selection popover.** Select text in a card body → popover at selection: input + 3 preset pills. Pills: Explain / ELI5 / Go deeper. Keys 1–3 fire.
- **Ask flow.** Selection highlighted, pending child card appears beside source, edge drawn, camera centers the new card.
- **Follow-up drawer.** Each answered card has a hover handle under it; clicking slides a drawer out with input + preset row. Escape or empty blur tucks it back; a draft keeps the handle marked. Touch shows the handle always. Card body never shrinks while typing.
- **Stream client.** POST ask text to mock SSE. Server mints the node id (unless retrying) and the FE adopts it from the first event. Presets applied client-side; server never knows.
- **Card states.** pending → streaming → answered; failed keeps reason + retry. Abort keeps partial text.
- **Failed card UI.** Red dot + one-line reason row, Retry in the card header. Composer hidden while failed. No modal or toast.
- **Header strip.** Parse `TITLE/SOURCES/FOLLOWUPS` before first body token. Title and sources appear before text finishes. Header never renders. Card header is a fixed row with status dot, ellipsized title, and actions (Stop while streaming, Retry on failure).
- **Sources.** Row under search-backed cards.
- **Follow-up chips.** Rendered from header; click fills the drawer, does not submit.
- **Retry.** Same node id, new stream.

## Mock SSE

Variants: normal, slow tokens, mid-stream error, empty sources. Selected via `x-mock-scenario` header (tests only; FE has no scenario knowledge). Deterministic timings for tests.

## Tests

- Playwright against mock SSE.
- Four states reached and styled.
- Title, sources, chips appear before stream ends.
- Header never leaks into body.
- Retry reuses node, recovers.
- Abort keeps partial text.
- Screenshot stable surfaces: answered card with sources + chips and open follow-up drawer. Desktop + mobile. No streaming screenshots.

## Non-goals

No real model, graph, search, auth. No preset settings, notes, ⌘K, PWA. M3 onward.
