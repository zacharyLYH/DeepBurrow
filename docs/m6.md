# M6 — Auth and user data isolation (shipped)

M6 established authenticated accounts, refreshable sessions, and user-scoped reads/writes for burrows, nodes, settings, and runs. Its initial login method used email and password.

**Current auth method:** M9 replaces password login with six-digit email-code login. Password fields, routes, and UI are removed in that milestone. The user-isolation and refresh-session guarantees from M6 remain.
